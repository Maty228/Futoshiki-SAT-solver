# Futoshiki SAT Solver

A Python implementation of a Futoshiki solver using SAT encoding and Glucose 4.2.

## Project Overview

Futoshiki is a logic puzzle played on an N x N grid.
The goal is to fill the grid with numbers 1 to N such that:
- Each row contains every number exactly once
- Each column contains every number exactly once
- All given inequality constraints are satisfied
- All predefined values remain unchanged

## Implementation

The puzzle will be encoded as a CNF formula in DIMACS format and solved using Glucose 4.2.
